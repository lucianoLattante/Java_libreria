# Java Library — contexto del proyecto

Aplicación histórica de aprendizaje con Java 8, Spring Boot, Spring MVC, Thymeleaf, JPA y MySQL. El código incluye libros, autores, editoriales, registro de usuarios y login mediante formularios.

Se conserva como antecedente técnico. No se presenta como sistema productivo ni se atribuye autoría individual sin evidencia de commits.

El [README principal](README.md) describe la estructura, las rutas, los requisitos y las instrucciones de evaluación local. El [análisis técnico](docs/TECHNICAL_REVIEW.md) distingue lo implementado de las mejoras propuestas.

**Estado de verificación:** esta actualización documental revisó código y enlaces; no ejecutó el arranque, MySQL, tests ni un despliegue. La protección CSRF, las reglas de autorización y las operaciones de escritura necesitan revisión antes de una demo pública.
